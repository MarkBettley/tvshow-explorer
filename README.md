# TV Shows Explorer

Aplicación web para explorar y buscar series de televisión utilizando la API pública de TVMaze.

El proyecto permite consultar series y acceder a información detallada y reparto mediante solicitudes asíncronas a una API REST.

## Funcionalidades

- Búsqueda de series por nombre.
- Catálogo inicial de programas.
- Consulta de detalles de una serie.
- Consulta del reparto.
- Navegación hacia una vista individual.
- Consumo de API REST mediante Axios.

## Tecnologías

- HTML5
- JavaScript
- Axios
- TVMaze API
- Sass / SCSS
- CSS3

## Estructura

- `Index.html` - explorador principal.
- `show-detail.html` - detalle de la serie.
- `js/app.js` - lógica y consumo de API.
- `scss/styles.scss` - estilos Sass.
- `css/styles.css` - estilos compilados.

## Uso

Clona el repositorio:

    git clone https://github.com/MarkBettley/tvshow-explorer.git

Abre `Index.html` en un navegador.
